# 🐟 PAL Fish Farm Website

A modern, responsive, and premium fish farm website built with **React** and **Vite**.

This project is being developed as a production-quality business website for **PAL Fish Farm**, focusing on modern UI/UX, reusable components, responsive design, accessibility, and maintainable architecture.

---

## 🌐 Project Overview

PAL Fish Farm is a premium fish farming business specializing in high-quality ornamental and freshwater fish.

The website is designed to:

- Showcase available fish varieties
- Present company information
- Display the fish gallery
- Highlight services
- Publish blog articles
- Allow customers to contact the farm
- Provide a premium and modern user experience

# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Pramod04Kaushal/PAL.git
```

Navigate to the project

```bash
cd PAL
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
